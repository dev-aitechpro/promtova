### Грабли, которые стоит помнить
- При разбиении файла скриптом по диапазонам строк: диапазоны должны быть непрерывными,
  иначе теряются строки; а если источник потом перезаписывается — берите оригинал из git
  (`git show <sha>:path`). Первый запуск стёр исходник — спасал baseline-коммит.
- `npm i -D eslint @eslint/js` подтягивает `@eslint/js` v10, который требует eslint v10 —
  нужно явно фиксировать мажорную версию (`@eslint/js@^9`).
- В тестах React+Zustand: подписывайтесь на примитив (строку), а не на объект, иначе
  эффект сброса формы будет срабатывать при каждом изменении стора.
