# Промтовая (Promtova) — IDE для промт-инжиниринга

Локальное приложение для хранения, организации и переиспользования промптов для LLM.
Работает полностью оффлайн и доступно в двух вариантах:

- **Веб-версия** — один автономный `index.html`, открывается в браузере без сервера
  (данные держатся в памяти сессии).
- **Нативная Windows-версия** — упаковано в Electron, данные хранятся в файле
  `%APPDATA%\Promtova\stores.json` на диске ПК.

**Версия:** 1.2.2 · **Лицензия:** MIT · © Pavel K. / Neurocode

## История версий

### v1.2.2 — исправление редактирования и работы с папками
- Исправлена периодическая блокировка ввода текста/выделения/курсора: глобальные
  хоткеи больше не перехватываются во время набора; убран полноэкранный оверлей
  дропдауна сортировки, перекрывавший редактор.
- Новые промпты создаются в **текущей** папке (не только в «Все промпты»).
- Кнопка копирования **названия** промпта отдельно от содержимого.
- Перемещение промпта в любую папку (селект в редакторе и на карточке списка).
- Импорт теперь создаёт **подпапки/категории** и сохраняет иерархию
  (в т.ч. блок-категории из путей вида «A/B/C»).

### v1.2.1 — обновление базы промтов из репозитория
- Новая кнопка «Обновить базу промтов» в сайдбаре скачивает каталог
  `community-prompts.json` из репозитория и открывает диалог объединения баз.
- Пользователь сам решает: загрузить новые промты или отказаться.
- Слияние только добавляет новые промты и не удаляет/не портит существующие
  наработки (конфликты решаются через MergeModal, по умолчанию дубли пропускаются).

### v1.2.0 — нативная Windows-версия
- Упаковка в нативное приложение (Electron), установщик `setup.exe` (NSIS).
- Нативное хранилище: данные — в файле `%APPDATA%\Promtova\stores.json` через `electron-store`
  (вместо `localStorage`).
- Нативные диалоги импорта/экспорта (`.prmt` / `.json` / `.md` / `.txt`).
- Автообновление через `electron-updater` (канал — GitHub Releases).
- Перенос данных из веб-версии (нативный импорт `.prmt`).
- В веб-режиме и тестах хранилище работает на in-memory адаптере; обращений к web-хранилищам
  (`localStorage` / `sessionStorage` / `indexedDB`) в рантайме нет.

## Запуск

```bash
npm install        # установить зависимости
npm run dev        # дев-сервер (Vite)
npm run build      # сборка в единый dist/index.html
npm run preview    # предпросмотр сборки
```

После `npm run build` полученный `dist/index.html` самодостаточен — его можно открыть
двойным щелчком, без хостинга.

```bash
npm run typecheck  # tsc --noEmit (strict)
npm run lint       # ESLint (flat config)
npm test           # Vitest, один прогон
npm run test:watch # Vitest в режиме наблюдения
```

## Возможности

### Промпты
- CRUD, дублирование, избранное, счётчик использований.
- **Обычный и шаблонный режим.** Шаблонный режим разделяет промпт на логические блоки
  **System Prompt / Context / Output format**; при копировании, экспорте, поиске и в превью
  они склеиваются в единый текст (`getPromptText`).
- **Переменные `{{name}}`** извлекаются из текста автоматически, значения подставляются
  при копировании. Есть очистка неиспользуемых значений.
- Три режима редактора: просмотр / правка / разделённый вид с Markdown-превью.

### Папки
- Иерархия произвольной вложенности: создание подпапок с выбором родителя.
- Папки идентифицируются стабильным `id`, поэтому **переименование не ломает иерархию**.
- Перемещение вверх/вниз среди папок одного уровня (поле `order`).
- Настраиваемые иконка и цвет.
- **Контекстное меню по правому клику:** переименовать, создать подпапку, переместить
  вверх/вниз, создать промпт, удалить.
- Удаление с подтверждением: показывается число затрагиваемых промптов и вложенных папок
  (удаление каскадное, по всему поддереву).

### Теги
- Выводятся автоматически из промптов, фильтрация по нескольким тегам одновременно.
- Пункт «По тегам» открывает окно со всеми тегами и активными фильтрами.

### Импорт / экспорт
- Экспорт в `.prmt` (JSON): полные данные промптов, переменные, теги, счётчики
  **и структура папок** (иерархия, иконки, цвета).
- Импорт `.prmt` / `.json` через **диалог объединения баз**: для каждого совпадения
  (пара «заголовок + папка») выбирается действие — пропустить, переименовать,
  заменить или дублировать. Есть массовые кнопки.
- Импорт `.md` / `.txt` — один промпт, папка берётся из текущей выбранной.
- Некорректные записи не «роняют» импорт, а перечисляются в диалоге.

### Обновление базы промтов
- Кнопка «Обновить базу промтов» в сайдбаре скачивает каталог `community-prompts.json`
  из репозитория и открывает диалог объединения.
- Можно принять (загрузить новые промты) или отказаться.
- Существующие промты и папки никогда не удаляются — добавляются только новые;
  совпадения по «заголовок + папка» по умолчанию пропускаются.
- Как добавить свой промпт в общий каталог: дополнить `community-prompts.json`
  в корне репозитория и открыть Pull Request.

### Оформление
- 7 предустановленных тем + редактор пользовательских тем с живым предпросмотром.
- Настройки автосохранения и размера шрифта редактора.

## Горячие клавиши

Список в приложении всегда синхронизирован с реализацией (`src/hooks/useGlobalHotkeys.ts`).

| Клавиши | Действие |
|---|---|
| `⌘/Ctrl + K`, `⌘/Ctrl + F` | Фокус на поиске |
| `⌘/Ctrl + N` | Создать новый промпт |
| `⌘/Ctrl + S` | Сохранить |
| `⌘/Ctrl + C` | Копировать промпт |
| `⌘/Ctrl + Shift + C` | Копировать с подстановкой переменных |
| `F2` | Переименовать выбранный промпт |
| `Esc` | Закрыть окно или контекстное меню |
| Правый клик по папке | Контекстное меню папки |

## Данные и совместимость

- Состояние хранится в `localStorage`: `promtova-state` (промпты, папки, настройки)
  и `promtova-theme` (темы).
- Схема версионируется (`version: 2`). При загрузке старых данных выполняется миграция:
  числовые id промптов становятся строками, названия папок в ссылках `parent`/`children`
  превращаются в стабильные `id`. Существующие данные не сбрасываются.
- Для резервного копирования используйте экспорт `.prmt` (кнопка «Экспорт»).

## Безопасность

Markdown-рендер экранирует ввод и разрешает только безопасные схемы ссылок
(`http`, `https`, `mailto`, относительные) — `javascript:` и `data:` отклоняются.
Поведение покрыто тестами в `src/utils/promtova.test.ts`.
